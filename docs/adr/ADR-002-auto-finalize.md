# ADR-002: ประกาศผลอัตโนมัติ 14 วันหลังปิดรับ (Figma J24) ที่ขัดกับ PRD

## Status

Proposed — ทำตาม Figma ไว้แล้วแต่ **ยังต้องให้ทีมหรืออาจารย์ผู้สอนตัดสินนโยบาย** เพราะเป็นเรื่องการให้เกรด ไม่ใช่เรื่องเทคนิค
ระหว่างนี้ปิดได้ทั้งระบบด้วย `AUTO_FINALIZE_ENABLED=false`

## Date

2026-10-19

## Context

เอกสารสองชุดขัดกัน:

- [PRD](../../Sources/SDPX-AI-main/project-ideas/pairwise_evaluation_prd.md) G3 "ให้อาจารย์ตรวจสอบและแทรกแซงผลได้ทุกจุด (ระบบไม่ตัดเกรดเอง)"
  และ §7.3 state machine `CLOSED --> FINALIZED: instructor กด Finalize`
- Figma J24 (`334:1867`) แถบสถานะงานที่ปิดรับแล้ว: "ถ้ายังไม่ประกาศ ระบบจะประกาศอัตโนมัติวันที่ … (14 วันหลังปิดรับ)
  และเตือนคุณก่อน · ยกเว้นรายการที่ข้อมูลไม่พอ จะไม่ประกาศอัตโนมัติ"

CLAUDE.md กำหนดให้ยึดเอกสารต้นฉบับและแจ้งความขัดแย้ง ผู้ใช้สั่งในรอบนี้ว่า "ทำให้เหมือน Figma" จึงทำฟีเจอร์ตามแบบ
และบันทึกความขัดแย้งไว้ที่นี่ แทนการตัดสินนโยบายเอง

## Decision (ชั่วคราว)

ทำตาม Figma โดยจำกัดความเสียหายให้เหลือกรณีที่อาจารย์ "ลืมประกาศ" งานที่ข้อมูลพร้อมแล้วเท่านั้น
([app/auto_finalize.py](../../backend/app/auto_finalize.py)):

- ประกาศเฉพาะงานที่ **ยังไม่เคยประกาศ** และเลยกำหนดส่งสุดท้ายมาแล้ว 14 วัน
- **ข้ามทั้งงาน** ถ้ามีรายการข้อมูลไม่พอ (LOW_CONFIDENCE) หรือยังไม่มีคำตอบที่ส่งแล้วเลย — กฎเดียวกับ FR-SCORE-05
  ที่การประกาศด้วยมือต้องให้อาจารย์ยืนยันเอง · ผลคำนวณ final ที่เพิ่งเขียนถูก rollback
- **ไม่ประกาศซ้ำหลังอาจารย์ reopen** (`finalized_at` ไม่ว่าง) — การประกาศรอบหลังเป็นของอาจารย์เท่านั้น
- เตือนเจ้าของห้องในกระดิ่งล่วงหน้า 3 วัน · แถบสถานะบอกวันที่ล่วงหน้า · ไม่มีคะแนนในข้อความแจ้งเตือน (FR-NOTIF-06)
- บันทึก audit `SCORES_FINALIZED` ผู้กระทำ `system` และ `after_state.automatic = true`
- อาจารย์เปิดผลใหม่ (reopen) ได้ตามปกติ ถ้าไม่เห็นด้วยกับผลที่ระบบประกาศ
- `AUTO_FINALIZE_ENABLED=false` ปิดทั้งการประกาศ แถบสถานะ (`autoFinalizeAt` เป็น `null`) และการแจ้งเตือน พร้อมกัน

## Alternatives Considered

1. **ไม่ทำ ใช้ข้อความเดิมในแถบสถานะ** — ตรง PRD แต่ต่างจากแบบ และงานที่อาจารย์ลืมประกาศจะค้างโดยไม่มีอะไรเตือน
2. **เตือนอย่างเดียว ไม่ประกาศเอง** — ตรง PRD G3 และยังได้ประโยชน์ด้านการเตือน แต่ข้อความในแบบต้องเปลี่ยน
3. **ให้อาจารย์เปิด/ปิดได้ต่องาน** — ยืดหยุ่นที่สุด แต่ต้องเพิ่มคอลัมน์และหน้าตั้งค่าที่ไม่มีในแบบ

## Consequences

- หลัง deploy งานที่ปิดรับเกิน 14 วัน ยังไม่เคยประกาศ และข้อมูลครบ จะถูกประกาศภายใน 15 นาที —
  ควรตรวจข้อมูลบนเซิร์ฟเวอร์ก่อนเปิดใช้ หรือตั้ง `AUTO_FINALIZE_ENABLED=false`
- ถ้าทีมเลือกทางเลือก 1 หรือ 2 ให้ตั้งสวิตช์เป็น false ไว้ก่อน แล้วแก้ข้อความใน Figma J24 ให้ตรง
