# ADR-002: ประกาศผลอัตโนมัติ 14 วันหลังปิดรับ (PRD OQ-3 / Figma J24)

## Status

Accepted — 2026-10-20 · เปิดเป็นค่าเริ่มต้น (`AUTO_FINALIZE_ENABLED` ค่าเริ่มต้น `true` และตั้ง `"true"` ใน `render.yaml` /
`render.production.yaml`) · ปิดได้ด้วย `AUTO_FINALIZE_ENABLED=false`

ฉบับก่อนหน้า (Proposed, 2026-10-19) สรุปว่าฟีเจอร์นี้ขัดกับ PRD และปิดไว้ — สรุปผิดเพราะอ่าน PRD ไม่ครบ ดู Context

## Date

2026-10-19 (Proposed) · 2026-10-20 (Accepted)

## Context

ฉบับแรกอ้างเฉพาะ PRD G3 "ระบบไม่ตัดเกรดเอง" และ §7.3 `CLOSED --> FINALIZED: instructor กด Finalize`
แล้วสรุปว่า Figma J24 ขัดกับ PRD แต่ [PRD](../../Sources/SDPX-AI-main/project-ideas/pairwise_evaluation_prd.md) ตอบเรื่องนี้ไว้แล้ว:

- **§17 OQ-3** "ถ้าอาจารย์ไม่กด Finalize เลยจนจบเทอม ระบบควรทำอย่างไร" — Default ถ้ายังไม่ตอบ:
  **"auto-finalize หลัง deadline 14 วัน พร้อมแจ้งเตือน"** (ผู้ตัดสิน: Product · ก่อน M3)
- **FR-SCORE-05** item ที่ comparison < `min_comparisons` "MUST ถูก flag `LOW_CONFIDENCE` และ**ไม่ finalize อัตโนมัติ**"
  — ข้อกำหนดนี้มีความหมายก็ต่อเมื่อระบบ finalize อัตโนมัติได้

G3 / §7.3 อธิบายทางปกติที่อาจารย์ประกาศเอง ส่วน OQ-3 คือทางสำรองเมื่ออาจารย์ไม่ประกาศ จึงไม่ขัดกัน
และ Figma J24 ("ระบบจะประกาศอัตโนมัติวันที่ … (14 วันหลังปิดรับ) และเตือนคุณก่อน · ยกเว้นรายการที่ข้อมูลไม่พอ")
ตรงกับ OQ-3 + FR-SCORE-05 ทุกข้อ · ยังไม่มีคำตอบอื่นจาก Product ค่าเริ่มต้นของ OQ-3 จึงมีผล

## Decision

เปิดการประกาศผลอัตโนมัติเป็นค่าเริ่มต้น ([app/auto_finalize.py](../../backend/app/auto_finalize.py)):

- ประกาศเฉพาะงานที่ **ยังไม่เคยประกาศ** และเลยกำหนดส่งสุดท้ายมาแล้ว 14 วัน (OQ-3)
- **ข้ามทั้งงาน** ถ้ามีรายการข้อมูลไม่พอ (LOW_CONFIDENCE) หรือยังไม่มีคำตอบที่ส่งแล้วเลย (FR-SCORE-05)
  · ผลคำนวณ final ที่เพิ่งเขียนถูก rollback
- **ไม่ประกาศซ้ำหลังอาจารย์ reopen** (`finalized_at` ไม่ว่าง) — การประกาศรอบหลังเป็นของอาจารย์เท่านั้น
- เตือนเจ้าของห้องในกระดิ่งล่วงหน้า 3 วัน (OQ-3 "พร้อมแจ้งเตือน") · แถบสถานะบอกวันที่ล่วงหน้า · ไม่มีคะแนนในข้อความ (FR-NOTIF-06)
- บันทึก audit `SCORES_FINALIZED` ผู้กระทำ `system` และ `after_state.automatic = true`
- อาจารย์เปิดผลใหม่ (reopen) ได้ตามปกติ ถ้าไม่เห็นด้วยกับผลที่ระบบประกาศ — G3 "แทรกแซงผลได้ทุกจุด" ยังเป็นจริง
- `AUTO_FINALIZE_ENABLED=false` ปิดทั้งการประกาศ แถบสถานะ (`autoFinalizeAt` เป็น `null`) และการแจ้งเตือน พร้อมกัน

## Alternatives Considered

1. **ปิดไว้ อาจารย์ประกาศเองเท่านั้น** (ฉบับ Proposed) — งานที่อาจารย์ลืมประกาศค้างโดยไม่มีอะไรเตือน และขัดกับ OQ-3 / Figma
2. **เตือนอย่างเดียว ไม่ประกาศเอง** — ไม่ครบตาม OQ-3 และต้องแก้ข้อความใน Figma J24
3. **ให้อาจารย์เปิด/ปิดได้ต่องาน** — ยืดหยุ่นที่สุด แต่ต้องเพิ่มคอลัมน์และหน้าตั้งค่าที่ไม่มีในแบบ

## Consequences

- deploy ครั้งแรกหลังเปลี่ยน: งานที่ปิดรับเกิน 14 วัน ยังไม่เคยประกาศ และข้อมูลครบ จะถูกประกาศภายใน 15 นาที
  (loop ใน `app/daily_scoring.py`) — นักศึกษาได้แจ้งเตือนผลประกาศ (FR-NOTIF-04)
- ถ้า Product ตอบ OQ-3 เป็นอย่างอื่นภายหลัง ตั้ง `AUTO_FINALIZE_ENABLED=false` ได้ทันทีโดยไม่ต้องแก้โค้ด แล้วแก้ ADR นี้
