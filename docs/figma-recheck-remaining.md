# เทียบ Figma หน้าที่เหลือ และงานที่ต้องมี backend รองรับ

วันที่: 19 ตุลาคม 2026 · Branch: `codex/figma-frontend`

ต่อจากรอบก่อน (commit `83ca403`) ที่ยังค้าง: เทียบแบบละเอียดหน้าที่ยังไม่ได้วัด และงานที่ต้องให้ backend เก็บสถานะเพิ่ม

## วิธีวัด

- **Figma**: เปิดไฟล์แบบดูอย่างเดียว (ไม่ได้ล็อกอิน จึงไม่มีแผง inspect และส่งออกภาพไม่ได้) ซูม 50% / 100% แล้ววัดจากภาพหน้าจอ
  ภาพ 100% ของ pane = 1.152 px ต่อ 1 px ของแบบ — วัดเทียบกับความกว้างเฟรมที่รู้ค่า (1440 / 390) ทุกครั้ง
- **เว็บ**: ถ่ายด้วย Playwright + Edge headless ที่ 1440 px (เดสก์ท็อป) และ 390 px (มือถือ) จาก stack ในเครื่อง พร้อมข้อมูลเดโมที่สร้างผ่าน API
- ความแม่นยำโดยประมาณ ±4 px ที่ 100% และ ±8 px ที่ 50% · ไม่ได้ใช้ข้อมูล metadata ของ Figma เพราะไม่มีสิทธิ์ inspect
- Figma บล็อก headless browser จึงดึงภาพเฟรมอัตโนมัติไม่ได้ (ไม่ได้พยายามเลี่ยงการบล็อก)

## ยังต่างจากแบบ (ต้องตัดสินใจหรือทำต่อ)

- **J24 แถบสถานะ**: แบบเขียนว่าระบบจะประกาศผลอัตโนมัติ 14 วันหลังปิดรับ แต่ระบบไม่มีการประกาศอัตโนมัติ จึงไม่ใส่ข้อความนี้ (ต้องตัดสินใจว่าจะทำฟีเจอร์นี้หรือแก้แบบ)
- **J25 / J35 เป็นหน้าแยกในแบบ**: เว็บยังแสดงในส่วน "คะแนนของงาน" ของห้อง และส่วนคำร้องในหน้าภาพรวมงาน (เนื้อหาตารางตามแบบแล้ว)
- **J26 ปุ่ม "ประเมินเอง / สั่งให้ประเมินเพิ่ม"**: แบบวางไว้ท้ายการ์ดโดยไม่มีวิธีเลือกคู่ในเฟรม เว็บจึงคงปุ่มไว้ในแถวที่ข้อมูลไม่พอ
- **J28 แถว QS-07 "ปรับในงานถัดไป"** และ footer QS-06: ยังคำนวณ QS-06/07 ไม่ได้ตามข้อจำกัดเดิม
- **ภาพประกอบหัวหน้า J06 และ J26**: แบบใช้ภาพคนละภาพกับเว็บ แต่ส่งออกจาก Figma ไม่ได้เพราะไม่ได้ล็อกอิน
- **J13a**: แบบใช้ช่องเดียว "60% – 100%" เว็บใช้สองช่องที่มีหน่วย % · เว็บมีช่องคำถามต่อเกณฑ์เพิ่ม (มาจากเฟรมอื่น)
- **Nav มือถือ**: โลโก้ในแบบใหญ่กว่า และไม่มีไอคอนออกจากระบบ (เว็บคงไว้เพื่อให้ออกจากระบบได้)
- **ยังไม่ได้วัด**: M05 (bottom sheet ส่งไม่ครบ), M06 (ส่งสำเร็จ), J29 วัดเชิงโครงสร้างเท่านั้น

## Backend ที่เพิ่ม

- `quality_review`, `export_log` (migration `022`)
- `POST /api/assignments/{id}/quality/{key}:reviewed`, `POST /api/assignments/{id}/reports:export`, `GET /api/assignments/{id}/exports`
- `/scores` คืน `criteria[]`, `overridden`, `formulaVersion` · coverage คืน `instructorCount`, `pendingCount`, `meanScoreA` · รายการงานคืน `finalizedAt`
- CORS expose `Content-Disposition` (เดิมไฟล์ที่ดาวน์โหลดจากหน้าเว็บได้ชื่อสำรอง)
