- ภาพ Figma ดึงจาก Figma MCP ที่ขนาด 1440 px
- ภาพเว็บถ่ายจาก dev stack ในเครื่อง (`docker compose up`) ที่ viewport 1440×900 ด้วย Chrome headless ล็อกอินผ่าน test session (`/api/test/session`)

- Navbar: อีเมล, avatar, กระดิ่งพร้อม badge จำนวน, ปุ่มออกจากระบบ
- **การแจ้งเตือนครบทั้ง 5 ประเภทใน Figma** มี backend รองรับแล้ว (`pg_notification_repo.py`):

  | ประเภทใน Figma | event ใน backend |
  |---|---|
  | เปิดให้ประเมิน | `published` |
  | เหลือ 48 ชม. | `due` |
  | คู่ถูกจัดใหม่ | `regenerated` |
  | ประเมินเพิ่ม | `assigned` |
  | ประกาศผล | `finalized` |

  ทุกรายการมีลิงก์ไปหน้าที่ต้องทำ และไม่มีคะแนนในข้อความ ช่องว่างที่เหลือเป็นเรื่องเนื้อหา (B-20 ถึง B-23)
- การแบ่ง section "งานประเมิน" / "งานประเมินที่ทำไปแล้ว" และ pill "ประกาศผลแล้ว" สีเขียว
- ตัวกรองงานในหน้าห้องทำงานได้จริง
